# 식구봇 — 데드 바이 데이라이트 정보 디스코드 봇

Dead by Daylight의 **퍽·아이템·에드온·살인마** 정보를 한글·영문으로 찾아 주는 디스코드 봇이에요.
채팅만으로 쓰는 검색 채널, 주간 비밀의 신전 자동 알림, 랜덤 빌드 뽑기, 퍽 이름 맞히기 퀴즈가 있어요.

> 비공식 팬 프로젝트예요. Behaviour Interactive와 관련이 없고, *Dead by Daylight*는 해당 회사의 상표예요.

## 기능

| 기능 | 설명 |
|---|---|
| `#검색` 채널 | 검색어만 입력하면 퍽·아이템·에드온을 이름(한글·영문), 살인마 이름, 설명 문구로 찾아요. 결과가 여러 개면 선택창이 뜨고, 채널에는 항상 마지막 결과 하나만 남아요. |
| `#주간신전` 채널 | 새 비밀의 신전이 시작되면 이번 주 퍽 4개를 자동으로 올리고, 지난주 메시지는 지워요. |
| `#랜덤퍽` 채널 | 버튼으로 랜덤 빌드를 뽑아요. 생존자는 아이템 + 에드온 2개 + 퍽 4개, 살인마는 살인마 + 에드온 2개 + 퍽 4개예요. |
| `/퀴즈` | 나만 볼 수 있는 임시 채널에서 퍽 아이콘을 보고 이름을 맞혀요. 3분 동안 입력이 없으면 채널이 사라져요. |

봇이 보내는 모든 메시지는 알림 없이(silent) 보내요. 채널에 쓰는 사용 안내는 [봇_사용법.md](봇_사용법.md)를 보세요.

## 준비물

- Python 3.11 이상
- MySQL 8 (퍽·아이템·에드온 데이터를 저장해요)
- 디스코드 봇 토큰 ([개발자 포털](https://discord.com/developers/applications))
  - 포털의 **Bot → Message Content Intent**를 켜야 해요. 검색 채널과 퀴즈가 채팅 내용을 읽어요.
  - 서버에 초대할 때 `bot`, `applications.commands` 범위를 선택해요.

## 설치와 실행

```bash
pip install -r requirements.txt
```

환경변수를 설정해요. **토큰과 비밀번호는 코드나 저장소에 넣지 마세요.**

| 환경변수 | 필수 | 설명 |
|---|---|---|
| `DISCORD_TOKEN` | ✔ | 디스코드 봇 토큰 |
| `DB_PASSWORD` | ✔ | MySQL 비밀번호 |
| `DB_HOST` | | 기본값 `127.0.0.1` |
| `DB_USER` | | 기본값 `root` |
| `DB_NAME` | | 기본값 `dbd` (없으면 자동으로 만들어요) |
| `GUILD_ID` | | 지정하면 그 서버에 명령어가 바로 등록돼요 |
| `SHRINE_CHANNEL_ID` | | 주간 신전을 올릴 채널 ID |
| `SEARCH_CHANNEL_ID` | | 자동 검색 채널 ID |
| `RANDOM_CHANNEL_ID` | | 랜덤 빌드 버튼 채널 ID (`0`이면 꺼짐) |

채널 ID는 디스코드의 **개발자 모드**를 켠 뒤 채널을 우클릭해서 복사해요. 코드에 들어 있는 기본값은 만든 사람의 서버 채널이라 **자기 서버의 ID로 바꿔야 해요** (`bot.py` 위쪽 또는 환경변수).

데이터를 처음 채우고, 봇을 실행해요.

```bash
python dbd/sync_perks.py   # 퍽 + 살인마·아이템·에드온까지 모두 가져와 DB에 저장해요
python bot.py
```

게임이 업데이트되면 `python dbd/sync_perks.py`를 다시 실행하면 돼요. 여러 번 실행해도 안전해요.

## 봇에 필요한 권한

- 서버: **채널 관리** (`/퀴즈`가 임시 채널을 만들어요)
- `#검색`: 채널 보기, 메시지 보내기, 링크 임베드, 메시지 기록 보기, **메시지 관리** (사용자 글을 지워요)
- `#주간신전`, `#랜덤퍽`: 채널 보기, 메시지 보내기, 링크 임베드, 메시지 기록 보기
- `/퀴즈` 채널은 `봇이랑놀자`라는 이름이 들어간 카테고리 아래에 만들어져요 (`bot.py`의 `QUIZ_CATEGORY_NAME`).

봇을 켤 때 각 채널에서 부족한 권한을 터미널에 알려줘요.

## 데이터 출처

- 이름·설명·소유자·희귀도: 커뮤니티가 운영하는 [dbd.tricky.lol](https://dbd.tricky.lol) API (비공식, 영문·한글)
- 이미지: [Dead by Daylight Wiki](https://deadbydaylight.wiki.gg)의 이미지 주소를 **연결만** 해요 (파일을 저장하지 않아요)
- 폐기된 에드온은 위키의 `Decommissioned Add-ons` 분류와 비교해서 걸러내요

두 곳 모두 비공식이라 주소나 형식이 바뀌면 동작이 달라질 수 있어요.

## 데이터 보정 파일

API가 알려주지 않는 부분은 `dbd/` 폴더의 JSON으로 직접 고쳐요. 수정한 뒤 `python dbd/sync_perks.py`를 실행하면 반영돼요.

| 파일 | 용도 |
|---|---|
| `image_overrides.json` | 이미지를 자동으로 못 찾은 항목의 이미지 주소 |
| `tunable_overrides.json` | 설명에 수치가 빠진 항목의 수치 |
| `event_addons.json` | 이벤트 에드온 지정 (`{"에드온ID": "이벤트 이름"}`) |
| `perk_renames.json` | 퍽의 예전 이름 (`{"퍽ID": {"ko": "...", "en": "..."}}`) |

한글 상태 효과 이름(탈진, 인내 등)은 `dbd/sync_perks.py`의 `KEYWORDS_KO`에서 고쳐요.

## 구조

```
bot.py              디스코드 봇 (검색 채널, 주간 신전, 랜덤 버튼, 퀴즈)
dbd/
  schema.sql        MySQL 테이블
  queries.py        봇이 쓰는 DB 조회 (검색, 랜덤 빌드 등)
  sync_perks.py     퍽 동기화 (끝나면 sync_gear.py도 이어서 실행)
  sync_gear.py      살인마·아이템·에드온 동기화
  *.json            데이터 보정 파일
```
